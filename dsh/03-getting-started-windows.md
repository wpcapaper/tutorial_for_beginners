# 第三章：Windows 从零开始（本教程主线）

[返回教程首页](README.md) · [上一章：和其他工具比一比](02-compare-with-others.md) · [下一章：macOS / Linux 快速上手](04-getting-started-unix.md)

这一章，我们一步步在 **Windows** 上把 DeepSeek Harness 装好、配好，并让它干第一件活。

全程只需要你：

1. 装一个软件（Node.js，跟着点"下一步"就行）；
2. 敲**一条**命令；
3. 剩下全部在网页里用鼠标完成。

> 预计用时：30 分钟左右。第一次启动要下载东西，会慢一点，属正常。

---

## 3.1 开始前的准备（1 分钟）

- [x] 一台 Windows 10 或 Windows 11 电脑
- [x] 能上网
- [x] 一个 DeepSeek 账号（后面申请 API 密钥用，注册地址：[platform.deepseek.com](https://platform.deepseek.com/)）

## 3.2 第一步：安装 Node.js（约 5 分钟）

DeepSeek Harness 是跑在 Node.js 上的，所以要先装 Node.js [1]。官方对版本的要求是 **Node.js 22.19 以上（或 24 以上）**[5]，我们去官网下载最新的 LTS（长期支持版）就肯定满足。

1. 打开浏览器，访问 Node.js 官网：[https://nodejs.org/](https://nodejs.org/) [29]
2. 点击首页上大大的 **LTS** 按钮（左边那个，写着 "LTS" 的），下载 Windows 安装包（`.msi` 文件）。
3. 双击下载好的安装包，一路点 **Next（下一步）**，最后点 **Install（安装）**。所有选项保持默认即可，不用改。
4. 装完后验证一下：按键盘上的 `Win` 键，输入 `PowerShell`，打开 **PowerShell**（黑色/蓝色窗口，这就是"命令行"）。在里面敲：

   ```powershell
   node -v
   ```

   然后回车。如果看到类似 `v24.x.x` 的一行字，说明装好了 ✅。

   > 如果提示"无法识别 node"，多半是安装时没勾选自动加入 PATH，或者装完没重启 PowerShell——关掉窗口重新打开一个试试。还不行就重启电脑再试。

## 3.3 第二步：建一个"工作文件夹"，然后启动 dsh（约 5 分钟）

dsh 会在你指定的文件夹里干活（这个文件夹官方叫**工作区**，3.6 节会细说）[4]。所以我们先建一个专门给它用的文件夹，**然后就在这个文件夹里启动它**——官方文档原话："`dsh` 进程会把启动时所在的目录作为默认文件系统位置" [4]。

1. 在资源管理器里随便找个地方建文件夹，比如 `D:\mywork`（或者 `C:\Users\你的用户名\mywork`，都行）。
2. 打开 PowerShell，**进入这个文件夹**（把下面的路径换成你自己的）：

   ```powershell
   cd D:\mywork
   ```

3. 然后敲这一条命令并回车——**这就是全教程最重要的一条命令**：

   ```powershell
   npx @deepseek-ai/dsh web
   ```

   命令的意思是：用 npx 工具运行 DeepSeek Harness 的 `web`（网页版）[1]。

4. 第一次运行，npx 会问你是否要安装这个包，输入 `y` 回车，然后等待下载（视网速可能几分钟）。
5. 下载完成后，dsh 会启动，并在屏幕上打印一行地址，然后**自动用默认浏览器打开网页界面**。默认地址是：

   ```
   http://127.0.0.1:3080
   ```

   > 如果你不希望它自动开浏览器，可以加参数 `--no-open` [1]。这条地址里的 `127.0.0.1` 意思是"只在你本机访问"，别人访问不到，放心。

6. 浏览器打开后，你应该能看到 DeepSeek Harness 的网页界面（Web UI）。**这个 PowerShell 窗口先别关**——关掉它 dsh 就停了。

## 3.4 第三步：申请 DeepSeek API 密钥（约 5 分钟）

dsh 的"大脑"是 DeepSeek 的模型，调用它需要一把钥匙——**API 密钥**（API Key）[7]。

1. 打开 [https://platform.deepseek.com/](https://platform.deepseek.com/)，注册/登录 DeepSeek 开放平台 [28]。
2. 在平台里找到"API Keys"（API 密钥）页面，创建一个新的密钥。
3. 创建后**立刻复制保存**——密钥通常只显示一次，弄丢了就得重新建。
4. 平台会给账号充值或赠送一些额度，模型按用量计费，价格以官网为准。

> 小知识：这个密钥很"私密"，相当于你钱包的钥匙。dsh 官方把密钥存在 `$DSH_HOME\.credentials.yaml` 文件里（Windows 上一般是 `C:\Users\你的用户名\.dsh\.credentials.yaml`），而且官方说密钥是"只写"的——保存后界面只会显示脱敏的代号，不会把明文密钥暴露出来 [7]。

## 3.5 第四步：在网页里配置模型（约 2 分钟）

1. 在 dsh 网页界面里，打开 **设置 → 模型**（Settings → Models）[4][7]。
2. 找到 **DeepSeek** 卡片，把刚才复制的 API 密钥粘贴进去，保存。
3. 官方原话："模型路由会立即可用，不需要重启服务器。" [4]

> 如果以后你用的是别的模型服务（比如 OpenAI、Anthropic，或者公司内部网关），官方有完整的[模型配置指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/providers.zh.md) [7]。小白阶段我们只用 DeepSeek 官方模型就够了。

## 3.6 第五步：选择工作区（约 2 分钟）

1. 在网页界面里找到 **选择工作区**（Choose workspace）按钮。
2. 点击后**添加**你刚才建的那个文件夹（`D:\mywork`，也就是你启动 dsh 时所在的目录），然后**选中它**。
3. 官方原话："选中工作区前，会话输入框不可用。" [4]——选好工作区，底部的对话框才能输入。

**工作区 = AI 干活的地盘。** dsh 默认情况下主要就在这个文件夹里读文件、写文件，超出范围的操作会触发权限管控（见 3.8 节）。

## 3.7 第六步：派第一个活！🎉（约 5 分钟）

现在开始干活。在对话输入框里，用大白话给你的 AI 助手派任务。

**第一个任务（强烈建议先试这个）：**

> 请介绍一下这个文件夹里都有什么文件，每个文件大概是干什么的。

dsh 会：搜索文件夹 → 逐个读取文件 → 给你一份总结。你会发现它"真的在动手"。

**更多可以试的任务：**

| 任务类型 | 可以这样说 |
|---|---|
| 整理文件 | "帮我把这个文件夹里的图片按月份分类，放到不同子文件夹里" |
| 写文档 | "帮我把这周的会议记录整理成一份 Markdown 周报" |
| 查资料 | "在这个文件夹里找出所有提到'预算'的地方，汇总成表格" |
| 改内容 | "把所有文件里的旧电话 12345678 替换成 87654321" |
| 跑脚本 | "写一个 Python 脚本统计 CSV 文件的行数并运行它" |
| 长期任务 | "从今天起，每天帮我检查这个文件夹，新增的文件自动整理" |

官方给出的示例任务是：

> "Summarize this repository and identify its main packages."（总结这个代码仓库，并找出它主要的包。）[4]

你可以直接用它，也可以换成上面那些中文任务。

**你会看到什么：** AI 会一边干活一边"播报"它的思考过程——读哪个文件、改哪个文件、跑了什么命令，界面上都有记录。干完活它会给你总结。

## 3.8 关于"审批"：AI 什么时候会问你？

官方原话："如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。" [4]

意思是：**AI 准备做某些"有影响的操作"时（比如删除文件、装软件、跑陌生命令），会弹窗问你"可以吗？"，你点同意它才继续。**

- 默认情况下，dsh 的权限预设是 **`workspace-write`（工作区可写）+ `ask`（询问）**：AI 可以在你的工作区文件夹里自由读写，但涉及更广范围的操作会先问你 [27]。
- 权限模式一共三档 [10]：
  - **read-only（只读）**：AI 只能看，不能改任何东西；
  - **workspace-write（工作区可写）**：AI 能在工作区里读写（**默认档**）；
  - **danger-full-access（完全访问）**：AI 可以动你电脑上的几乎所有东西（**不推荐小白用**）。
- 审批策略两档：**ask（询问，默认）** 和 **never（永不询问，一律拒绝）** [9][27]。

> **给小白的安全建议：** 保持默认的"工作区可写 + 询问"就行。AI 问你要不要执行某个操作时，先看一眼它要干什么，拿不准就点"拒绝"，再换个说法重新吩咐它。永远不要在自己没看清楚时点"完全访问"。

## 3.9 Windows 用户专属说明（重要，但不是出错）

1. **Windows 上 AI 用的是 PowerShell，不是 bash。** 官方在 dsh-base 组合包说明里写明：Windows 上没有 bash 的运行器，所以 dsh 在 Windows 上挂载的是 PowerShell（pwsh）命令栈 [13]。AI 执行命令时会调用 PowerShell，这是设计如此，不是出错。
2. **PowerShell 版本。** dsh 会按顺序找 PowerShell：优先 PowerShell 7（通过官方安装的），其次是商店版，最后是 Windows 自带的 PowerShell 5.1 [27]。Windows 11 自带 5.1，能用；想更好用可以装 PowerShell 7（可选，不装也行）。
3. **临时目录。** Windows 下 dsh 会给每个会话分配一个独立的临时子目录用于临时文件，写入权限被限制在工作区和这个临时目录里 [13]。
4. **一切都在本机。** dsh 默认监听 `127.0.0.1`（仅本机），你的文件和对话不会上传到 DeepSeek 之外的任何地方（除了调用模型本身需要发送请求内容）[1]。

## 3.10 怎么停止 dsh？

干完活想关掉它：

- 回到那个 PowerShell 窗口，按 `Ctrl + C`，dsh 就停了；或者直接关掉那个 PowerShell 窗口。
- 下次要用，重新打开 PowerShell，`cd` 到工作文件夹，再敲一次 `npx @deepseek-ai/dsh web` 即可。
- 你的会话记录会保留（官方：会话日志是持久化的 [8]），下次启动后还能看到和继续之前的对话。

## 3.11 Windows 常见问题速查

| 问题 | 解决办法 |
|---|---|
| 提示 `node 不是内部或外部命令` | Node.js 没装好或 PATH 没配好，重装 Node.js 并重启 PowerShell / 电脑 |
| `npx` 下载特别慢 | 第一次下载整个 dsh 包本来就慢，耐心等；也可以配置 npm 国内镜像（可选，不影响正确性） |
| 提示 `3080 端口被占用` | 换一个端口：`npx @deepseek-ai/dsh web --port 8080` [11]，然后浏览器访问 `http://127.0.0.1:8080` |
| 防火墙/杀毒软件弹窗 | dsh 是本机服务（127.0.0.1），如弹出网络访问询问，选择允许或保持仅本机即可 |
| 浏览器没有自动打开 | 看 PowerShell 窗口里打印的地址，手动在浏览器里输入 |
| 界面上没有输入框 | 说明还没选中工作区，回到 3.6 节选择工作区 [4] |
| 报错 `MISSING_CREDENTIAL` | API 密钥没配置好，回到 3.5 节重新保存密钥 [7] |
| 报错 `UNKNOWN_MODEL` | 模型没选对，在模型选择器里选一个已配置的模型 [7] |

**这一章小结：** 装 Node.js → 建工作文件夹 → `npx @deepseek-ai/dsh web` 启动 → 配 API 密钥 → 选工作区 → 派活。恭喜，你已经能让 DeepSeek 在你的电脑上干活了！
