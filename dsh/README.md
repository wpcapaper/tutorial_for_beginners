# DeepSeek Harness 小白入门教程

> 用大白话，从零开始学会用 DeepSeek Harness（简称 `dsh`）——让 DeepSeek 的 AI 在你自己的电脑文件夹里帮你干活。

本教程的目标只有一个：**读完并跟着做完，你就能像用 WorkBuddy 那样，用一句大白话给 DeepSeek 派活，看着它在你的电脑上把活干完。**

## 这份教程写给谁？

- 你是**完全的小白**——没写过代码、没装过开发工具，但你会正常使用电脑（会建文件夹、会复制粘贴、会装软件、会用浏览器）。
- 你不是**完全的小白**——你知道"文件夹"和"文件"的区别，知道"程序"和"网页"是怎么回事，愿意按教程敲一两条命令。
- 你**不需要**是程序员。DeepSeek Harness 目前定位不是 WorkBuddy 那种开箱即用的消费级软件，它要求使用者具备一点点基本电脑知识，这正是你有的那一点点。

> **先读这一节：** 如果你完全没碰过命令行（黑色的那个小窗口），也完全不用怕。本教程 Windows 部分只需要你敲**一条命令**，其余都在网页里用鼠标完成。

## 你会学到什么

学完本教程，你会：

1. 知道 DeepSeek Harness 到底是什么、和 Coze / WorkBuddy 有什么区别；
2. 在自己电脑上装好它（Windows 或 macOS / Linux）；
3. 配好模型，选好工作区（一个专门给它干活的文件夹）；
4. 用自然语言派活：整理文件、写文档、查资料、改代码、跑脚本；
5. 看懂它什么时候会"问你一声"（审批），知道怎么安全地让它干活；
6. 知道去哪儿看官方文档、去哪儿求助。

## 重要提醒（务必先看）

- **它是"开发者预览"阶段的软件。** 官方原话是："DeepSeek Harness 目前处于*开发者预览*阶段，正在快速迭代。**未来将出现破坏兼容性的变更。**" [1] 意思是：它可以用、能干活，但版本之间可能有变化，界面和命令以后可能不一样。
- **本教程基于 2026 年 8 月的最新版本（`0.1.1-rc.2`）撰写** [2]。如果以后界面变了，请以[官方文档](https://github.com/deepseek-ai/deepseek-harness)为准。
- **它免费开源（MIT 协议）** [1]，但调用 AI 模型需要[DeepSeek API 密钥](https://platform.deepseek.com/)（按用量付费，价格以官网为准）。
- 教程里所有"事实"都附了出处编号，完整清单见[第五章：参考文献](05-advanced-faq-references.md)。
