# 第一章：DeepSeek Harness 是什么

[返回教程首页](README.md) · [下一章：和其他工具比一比](02-compare-with-others.md)

这一章我们用大白话回答三个问题：

1. 智能体（Agent）是什么？
2. DeepSeek Harness 是什么？
3. 它具体能干什么？有哪些词我需要先搞懂？

---

## 1.1 先搞懂一个词：智能体（Agent）

你可能已经在各种新闻里见过"AI 智能体"这个词。用大白话说：

> **智能体 = 一个会用工具的 AI。**

普通的 AI 聊天（比如网页版 DeepSeek 聊天）只能"说话"——你问它答。而**智能体**除了会说话，还**会动手**：它能在你的电脑上读文件、改文件、运行命令、执行代码，然后把结果告诉你。

打个比方：

- 普通聊天 AI 像一个**只会出主意的顾问**——"你回去自己弄吧"；
- 智能体像一个**真的帮你干活的助手**——"好的，我现在就开始弄，弄完给你看"。

DeepSeek Harness 就是帮你把这个"会干活的助手"在自己电脑上跑起来的工具。

## 1.2 那"Harness"又是什么？

"Harness" 直译是"马具/挽具"，在软件里常指**把一堆零件组装起来、让它们协同工作的架子**。

官方对 DeepSeek Harness 的定义是（原文）：

> "DeepSeek Harness（`dsh`）是由 DeepSeek AI 开发的开源 agent harness（智能体框架）。" [1]

再通俗一点：**它是一套"智能体框架"**——就像汽车底盘和发动机是一套"造车框架"一样，dsh 是把"大模型 + 工具 + 权限 + 会话记录"组装成完整智能体的框架。你不需要自己从零拼装，装好 dsh，它就已经是一台能干活的车了。

## 1.3 它最特别的地方：一切皆插件

DeepSeek Harness 官方最强调的一个设计是：

> "它采用**一切皆插件**的架构，并由 Cordis 驱动。" [1]

"插件"这个词你应该不陌生——浏览器插件、游戏 Mod，都是往一个软件里"插"新功能。dsh 的特别之处在于，**它自己身上的所有部件都是插件**：模型怎么接、工具有哪些、会话怎么记录、AI 的"大脑回路"（官方叫 agent loop，智能体循环）本身……全都是插件 [3]。

这对你有什么意义？简单说：

- **想加功能，不用改主程序**，插个插件就行；
- **不喜欢默认行为，可以替换**，因为每个部件都能被换掉 [3]；
- 官方文档原话："不存在需要打补丁的特权内核：扩展 dsh 的方式是把插件挂载到其他插件旁边。" [3]

（这一节对你实际使用影响不大，先知道有这么回事即可，免得以后看到"插件"两个字发懵。）

## 1.4 一句话总结它的身份

| 问题 | 答案 | 出处 |
|---|---|---|
| 谁开发的？ | DeepSeek AI（深度求索） | [1] |
| 开源吗？ | 开源，MIT 协议 | [1] |
| 什么阶段？ | 开发者预览，快速迭代中，会有破坏性变更 | [1] |
| 跑在哪里？ | 跑在**你自己的电脑上**（本地） | [4] |
| 用什么语言/环境？ | 需要安装 Node.js（22.19 以上版本） | [5] |
| 怎么启动？ | 一条命令 `npx @deepseek-ai/dsh web` | [1] |
| 界面长什么样？ | 打开后是网页界面（Web UI），默认地址 `http://127.0.0.1:3080` | [1] |

## 1.5 它能干什么？（它的"工作能力"）

dsh 启动后，你会在网页里跟它对话。官方 Web UI 指南说：

> "Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。" [4]

翻译成大白话，它至少会这些本事：

| 本事 | 大白话解释 |
|---|---|
| 读文件 | 打开你文件夹里的文档、表格、代码，看懂内容 |
| 改文件 | 按你的要求修改、新建、删除文件 |
| 搜索 | 在你的一大堆文件里找关键词 |
| 运行命令 | 执行电脑命令（Windows 下用 PowerShell） |
| 执行代码 | 直接运行一段小程序 |
| 问你问题 | 拿不准的时候，会停下来问你（比如"删这个文件可以吗？"） |
| 制定计划 | 接到大任务时先列个步骤，一步步执行 |
| 委派子任务 | 把活拆开，派给"子助手"并行干 |
| 记住进度 | 会话记录会保存，下次可以接着聊 |

这些能力不是我们编的，是官方工具目录里真实登记的工具（工具名分别是 read、write、edit、glob、grep、bash/pwsh、run_code、ask_user_question、create_goal 等）[6]。

## 1.6 你需要先搞懂的几个名词

下面这些词，本教程后面会反复出现，现在花三分钟看懂，后面就不卡壳了。

| 名词 | 大白话解释 | 出处 |
|---|---|---|
| **模型** | 干活的"大脑"，就是 DeepSeek 的大模型。dsh 默认接 DeepSeek 官方模型 | [1][7] |
| **API 密钥** | 一把"钥匙"，证明你用的是自己的 DeepSeek 账号，按用量计费 | [7] |
| **工作区** | 你专门指定给 AI 干活的那个文件夹。AI 主要就在这个文件夹里读写文件 | [4] |
| **会话** | 一次对话的记录。AI 干过的活、说过的话都会记在会话里，可以回看、续聊 | [8] |
| **审批** | AI 做"危险操作"（比如删文件、装软件）前，弹窗问你"可以吗？"，你点头才继续 | [4][9] |
| **权限模式** | 规定 AI 能动哪些东西的开关，有"只读 / 工作区可写 / 完全访问"三档 | [10] |
| **沙箱** | 一道"隔离墙"，把 AI 跑的命令限制在安全范围内，防止它乱来 | [10] |
| **插件** | 可以插进 dsh 的功能模块，前面 1.3 节讲过 | [3] |
| **Profile** | 一套预先配好的"配置组合"，`web`（网页版）和 `headless`（命令行版）是自带的两个 | [11] |

> 小提示：官方有一份《术语表》，里面每个概念都有规范定义，觉得需要时可以去查：[官方术语表](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/glossary.zh.md) [12]。

## 1.7 它的"脾气"：现在还不是完美成品

讲完优点，也讲讲它的真实情况（诚实一点，免得你期望太高）：

1. **开发者预览阶段。** 官方明确说会有破坏兼容性的变更 [1]，意思是以后的版本可能改界面、改命令。
2. **对使用者有一点点要求。** 它不像 WorkBuddy 那样"下个 App 点点点就能用"，你至少要会建文件夹、装软件、敲一条命令。
3. **Windows 上用的命令工具是 PowerShell**，不是 Linux/Mac 上常见的 bash——这是正常现象，不是出错了（详见[第三章](03-getting-started-windows.md)）[13]。
4. **按量付费。** 软件本身免费开源，但调用 DeepSeek 模型需要 API 密钥，按用量计费（价格以 [DeepSeek 开放平台](https://platform.deepseek.com/)为准）[1][7]。

---

**这一章小结：** DeepSeek Harness 是 DeepSeek AI 开源的智能体框架，装在你自己的电脑上，用自然语言给它派活，它就在你指定的文件夹里读文件、改文件、跑命令，需要时会问你一声。它目前是开发者预览阶段，免费开源，但要求你有一点点基本电脑知识。
